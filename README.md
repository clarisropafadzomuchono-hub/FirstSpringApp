FirstSpringApp
Description
This project was developed as part of Exercise 16 - Task 1.

The application demonstrates:

Spring Boot setup
Spring MVC Controller
Request Mapping
Thymeleaf integration
Image integration using the Vistula University logo
Endpoints
Home Page
URL:

http://localhost:8080

Output:

Hello Vistula, in my first Spring controller.

Greeting Page
URL:

http://localhost:8080/greeting?name=Claris

Output:

Hello, Claris!

The page also displays the Vistula University logo.

Technologies Used
Java 21
Spring Boot
Maven
Thymeleaf
IntelliJ IDEA
